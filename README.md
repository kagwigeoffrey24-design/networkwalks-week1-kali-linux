\# Network Walks Week 1 - Kali Linux Lab Setup



\*Internship:\* Cybersecurity - NETWORKWALKS

\*Task:\* Installation of VirtualBox and Kali Linux



\## Objective

To setup a virtual lab environment for cybersecurity practice using VirtualBox and Kali Linux.



\## What I Did

\- Installed VirtualBox on Windows

\- Downloaded Kali Linux ISO from official website

\- Created my first VM with 4GB RAM

\- Completed Kali Linux installation

\- Practiced basic Linux commands: ls, pwd, ifconfig, ip a



\## Issues Faced \& Solution

Faced VT-x / virtualization error during VM start. Fixed by enabling Virtualization Technology in BIOS settings.
